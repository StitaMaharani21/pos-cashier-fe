# modules/owner/product-discount

"Diskon Otomatis": per-menu discounts applied to the cart without a code. Backed by `pos-kasir-be`'s `internal/master/discount` (product discount side): plain JSON CRUD at `/master/discounts/product-discounts` (`GET/POST/PUT/DELETE`, `:id` variants) through `shared/api/crud/createCrudService`, shown by `CrudSection` with `presentation="sheet"` (right-hand drawer).

Fields: `name`, `type` (`percent`|`fixed`), `value`, `max_discount` (percent only, **per unit**, 0 = no cap), `minimum_qty` (per menu line; the form's stepper starts at 1 and sends 0 for "no minimum"), `start_date`, `end_date` (**omitted = never expires**), `active_days` (`mon`..`sun`, empty = every day), `start_time`/`end_time` (`HH:MM` in the store's timezone, both empty = all day; end < start = crosses midnight and the early-morning part counts as the previous day), `status`, `menu_ids` (required, min 1 — `PUT` replaces the set wholesale). The backend enforces all of it in checkout pricing (`internal/transaction/pricing`) and in the menu list's `discount` badge.

The drawer (`components/ProductDiscountForm.tsx`) is built from `modules/owner/discount-form`'s shared cards: Informasi Diskon (name ≤50 + Aktif), Nilai Diskon (Persen/Nominal, Maksimal Potongan, Minimal Pembelian stepper), Periode Berlaku (presets Hari ini / 7 hari / 30 hari / Tanpa batas, plus the collapsible "Atur hari & jam"), Menu yang Kena Diskon (chips, first 8 then "+N lainnya"), a summary, then Batal / Simpan Diskon (Hapus on edit, asks twice).

`components/MenuPickerDialog.tsx` is "+ Pilih Menu": every menu in one request (`listMenus`, per_page 500, filtered client-side), search by name/code, category chips with counts in the category drag order, "Pilih semua di kategori ini", rows grouped by category with the price after the **draft** discount (preview only — `discount-form/lib/discount-rules.discountAmount` mirrors `pricing.DiscountAmountFor`), and an "Ada diskon lain" badge when the menu's current `discount` comes from another rule (the cashier takes the largest cut). The selection is local until "Terapkan".

Sublayers: `components/` (drawer form + menu picker), `schemas/` (zod, on top of `discount-form/schemas`), `columns/` (`CrudColumn<ProductDiscount>[]`), `section/` (`ProductDiscountSection.tsx`).
